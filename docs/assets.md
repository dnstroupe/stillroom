# Asset provenance

## Released soundtrack

Three original instrumental generations created in the user's Suno account for this project, using Suno v6 in the Stillroom Sessions workspace on 2026-11-15. Each request produced two versions; the bundled versions are identified below. Alternate versions remain in the Suno workspace.

- Blue Hour: 197.60 seconds. Suno song 457d6018-df00-4a05-accd-75369aac6b8a. Warm 88 BPM downtempo prompt with Rhodes, rounded bass, restrained broken beats and a resolved ending.
- Paper Lanterns: 223.12 seconds. Suno song f932b4b0-88f5-437d-ab80-8bd7f95d8d0d. Ambient jazz prompt with felt piano, upright bass and brushed drums.
- Soft Departure: 202.24 seconds. Melodic 108 BPM electronica prompt with analog arpeggio, rounded bass and restrained percussion.

The MP3s are downloaded source files, not previews linked to a temporary generation host. The music is AI-generated; no real performer or composer credit is invented. Publication here is for the user's portfolio demonstration, not a claim of exclusive copyright or a general redistribution license.
